# Fibonacci Multiplication in Lean 4

A Lean 4 formalization of Knuth's Fibonacci multiplication on the natural
numbers, with associativity proved using shifted Fibonacci sums and a
conjugate-error estimate.

## Main result

For natural numbers `a` and `b`, define

\[
a \circ b = \sum_{i \in I(a)} \sum_{j \in I(b)} F_{i+j},
\]

where `I(n)` is the set of indices in the Zeckendorf representation of `n`
and `F_0 = 0`, `F_1 = 1`.

The main theorem in this repository is:

```lean
FibonacciMultiplication.fibMul_assoc
```

The formal proof proceeds through:
- a shifted Fibonacci-sum function;
- a conjugate-error identity and uniform error bound;
- a shift-one identity obtained by showing two natural numbers differ by
  less than one;
- recurrence to extend the shift identity to every shift;
- a symmetric threefold expansion.

The use of the golden-ratio conjugate is not claimed as new. Arnoux used
the same conjugate-number viewpoint in his 1989 treatment. The aim here is
to provide a Lean 4 formalization and document this proof organization.

## Toolchain and dependency

The project configuration currently targets:

- Lean: `leanprover/lean4:v4.37.0-rc1`
- Mathlib: the `v4.37.0-rc1` tag

The original browser-based development did not record its exact Mathlib
revision. Therefore, this project configuration is a reproducibility
baseline to verify, not a claim that it recovers the exact original
environment. After a successful build, `lake-manifest.json` records the
resolved dependency revisions. Commit that manifest to version control.

## Build instructions

Install Lean 4 and Lake through `elan`, then run these commands from the
repository root:

```bash
lake update
lake exe cache get
lake build
```

To check the main source file directly:

```bash
lake env lean formalization.lean
```

If the build succeeds, keep the generated `lake-manifest.json` in the
repository. Do not manually invent or edit its commit hashes.

If `lake update` or `lake build` fails, do not describe this configuration
as verified. Record the error and adjust the toolchain and Mathlib revision
together.

## Checking theorem dependencies

The associativity theorem's reported axiom dependencies were inspected with:

```lean
#print axioms FibonacciMultiplication.fibMul_assoc
```

The reported output in the development environment was:

```text
[propext, Classical.choice, Quot.sound]
```

In particular, `sorryAx` was not listed. This output is a record from the
reported Lean environment; rerun the command after changing the toolchain
or Mathlib revision.

## Formalization outline

The main declarations include:

- `fibMul`: Fibonacci multiplication;
- `fibError_abs_lt`: the conjugate-error bound;
- `clean_partial_products_one`: the shift-one identity;
- `clean_partial_products`: the shift identity for all shifts;
- `knuth_threefold_expansion`: the threefold expansion;
- `fibMul_assoc`: associativity.
